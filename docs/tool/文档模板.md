# 文档模板

统一模板语法 `[suredt.指令:key]`，切换输出格式无需修改模板；支持 Word（.docx）变量替换、条件块、循环展开、图片替换、图表数据、页眉页脚；`classpath:` / `file:` / `http:` 多来源加载。已封版（除非明确需求不继续扩展）。
