# 表达式解析

条件表达式解析器（ANTLR 4）：6 大类运算符（比较、集合、模糊匹配、空值检查、逻辑、括号优先级），Visitor 输出 AST 可转 SQL / ES DSL / MongoDB Query；中英文关键字，大小写不敏感。被 [ES 搜索](../middleware/Elasticsearch.md) api 传递引入。
