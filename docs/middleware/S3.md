# S3 对象存储工具链

S3 协议接入：连接路由与客户端，支持 S3 / MinIO / 阿里云 OSS。

## 连接与路由（底层）

| SDK | javax | jakarta | 说明 | 文档 |
|-----|-------|---------|------|------|
| s3-route（simple-s3-route-starter） | 1.0.0 | 1.0.0 | S3 连接路由 | 模块 README |

## 客户端

| SDK | javax | jakarta | 说明 | 文档 |
|-----|-------|---------|------|------|
| [s3](../../sdk/oss/s3) | 1.0.0 | — | S3 回调事件实体类（非 client 的基础依赖） | [README](../../sdk/oss/s3/README.md) |
| [s3-client-starter](../../sdk/oss/s3-client-starter) | 2.1.0 | 1.0.0 | AWS S3 兼容客户端（S3/MinIO/阿里云 OSS，可选私有 CA 信任） | [README](../../sdk/oss/s3-client-starter/README.md) |

## 核心特性

- 桶/文件夹管理、对象上传下载/删除/查询/复制
- 版本历史、STS 临时凭证、预签名上传/下载 URL
- 对象标签、自动/手动分段上传、分段列表与中止
- 2.x 包名统一 `io.github.surezzzzzz.sdk.oss.s3`；1.x 旧包名已封版

> 矩阵实测（2026-10-07，JDK 17）：s3-route 与 s3-client 在 Boot 3.3.13 与 3.2.12 全量测试通过。
