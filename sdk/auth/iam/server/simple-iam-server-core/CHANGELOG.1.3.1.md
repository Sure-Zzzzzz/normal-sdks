# CHANGELOG - simple-iam-server-core 1.3.1

## 发布信息

- 版本：`1.3.1`
- 类型：Patch / 用户导入稳定契约补充
- 基线版本：`1.3.0`

## 版本定位

本版本为 IAM Server 的用户导入能力补齐跨层共享契约。Core 只定义模板结构、字段映射、数量上限和调用方可见的校验文案；Excel 解析、HTTP 接口、用户写入、日志与审计发布仍由 `simple-iam-server-starter` 负责。

## 主要变更

- **模板结构**：新增上传字段名、模板文件名、工作簿媒体类型、工作表名称、表头行和模板列宽常量；约束工作簿只能包含一个工作表。
- **字段映射**：新增固定六列的下标、字段名及不可变表头集合：`username`、`displayName`、`initialPassword`、`departmentCode`、`phone`、`email`。
- **导入限额**：新增单次最多 500 条非空数据行的统一常量，供模板生成与文件解析共用。
- **校验文案**：新增文件缺失、工作簿不可读、表头缺失或不匹配、行数超限、必填字段、部门不存在或停用及单行创建结果的统一脱敏文案。
- **审计边界**：不新增导入专用事件。成功行复用既有用户创建流程的 `CREATED/USER` 审计事件，避免形成两套同义审计语义。

## 依赖变更

无。

## 新增或扩展测试

本模块仅包含常量和文案契约，无运行时逻辑。`IamEventContractTest` 新增用户导入模板契约断言，并改为断言实际存在的 `ADMIN_CONSOLE_ENTRANCE_AUTHORITIES` 仪表盘入口权限集合；`simple-iam-server-starter` 的用户导入接口测试覆盖模板表头、损坏工作簿、非空行数量限制、行级失败结果，以及成功行复用用户创建审计事件的行为。

## 向后兼容性

纯增量发布：未删除或修改 1.3.0 的公开类型、方法、常量和值。既有 1.3.0 调用方可继续运行；使用用户导入能力的 Starter 需要编译到本版本以获得新增契约。

## 升级指南

将用户导入能力的使用方升级为依赖 `simple-iam-server-core:1.3.1` 的对应 IAM Server Starter 版本。仅升级 Core 不会自行暴露导入 HTTP 接口或执行用户创建。
