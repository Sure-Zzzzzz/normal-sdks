# CHANGELOG - simple-iam-server-core 1.1.3

## 发布信息

- 版本：`1.1.3`
- 类型：Patch / 向后兼容契约扩展
- 基线版本：`1.1.2`

## 版本定位

支撑 IAM Server 1.2.0 的可信应用安全生命周期（停用/恢复、异步删除清理）与 AKSK 所属人授权内部读取：本模块只补齐这两条链路所需的错误码、脱敏错误文案与共享常量，不引入 HTTP、存储或凭据实现。

## 主要变更

- 新增可信应用变更封锁与删除清理操作错误契约（`TRUSTED_APPLICATION_023` ~ `025`）与对应脱敏文案。
- 新增可信应用停用后令牌失效的 OAuth2 安全链拒绝文案（`TRUSTED_APPLICATION_TOKEN_INVALID`），停用/恢复不依赖独立错误码。
- 新增应用授权变更日志载荷无效契约（`APPLICATION_AUTHORIZATION_004`），服务授权最终态变更流的失败关闭语义。
- 新增可信应用删除清理的批量、租约与调度常量，以及 AKSK 所属人授权内部 reader API 路径常量（仅接受固定 SERVICE 短时 Bearer，不复用资源验证 Basic 或浏览器会话链）。

## 依赖变更

无。不引入新的运行时依赖，继续保持 Java 8 编译目标。

## 新增或扩展测试

无新增单测：本版为纯常量契约扩展，消费语义由 `simple-iam-server-starter` 1.2.0 的集成测试覆盖（可信应用生命周期、AKU 授权读取与 SSE 推送链路）。

## 向后兼容性

- 不移除或修改既有公开类型、常量、错误码和异常类型；新增内容均为向后兼容扩展。
- 错误码编号跳过 `TRUSTED_APPLICATION_022`（预置后随发版审查移除，编号不回收复用）。

## 升级指南

将依赖升级为 `io.github.sure-zzzzzz:simple-iam-server-core:1.1.3`。仅使用既有能力的调用方无需代码调整。
