# CHANGELOG - simple-iam-server-core 1.2.0

## 发布信息

- 版本：`1.2.0`
- 类型：Minor / 主体 ID 与手机号挑战契约
- 基线版本：`1.1.3`

## 版本定位

支撑 IAM Server 1.3.0（subjectId 全链切换与手机号三件套）：本模块只补齐两条链路所需的错误码、脱敏文案、默认策略常量与 Web 路径契约，不引入 HTTP、存储或凭据实现。策略默认值全部常量化并由 server-starter 配置项单一引用（阈值 / 窗口可配，缺省即本模块常量）。

## 主要变更

- **主体 ID**：新增生成器输出非法（`SUBJECT_ID_001`）与唯一冲突重试耗尽（`SUBJECT_ID_002`）错误契约及脱敏文案；新增默认主体 ID 长度（16 位全随机数字，首位可为 0，纯字符串无数值语义）与重试上限（5 次，耗尽即抛出不静默吞）常量。
- **手机号挑战**：新增验证码默认长度 6、挑战 TTL 300s、单挑战验证上限 5 次、同号发送冷却 60s、号 / IP / 全局三维频控默认阈值（1h×10 / 1h×20 / 1m×100）与 HMAC 密钥最小 32 字节启动校验常量；新增挑战业务前缀（活跃挑战映射 / 挑战详情 / 三维频控计数）与 `PHONE_CHALLENGE_PURPOSE_*` 用途常量（取值单一来源于 `simple-iam-core` 的 `SMS_PURPOSE_*`，双名同值防漂移）；新增手机号短信登录 provider 标识 `phone-sms`。
- **Web 路径契约**：新增手机号挑战创建（匿名 + 频控）、验证码登录（匿名，验证码即凭据）、忘记密码重置（匿名，不建会话）三个公开路径常量。
- **审计**：`AdminActionType` 新增 `PHONE_BOUND` / `PHONE_UNBOUND`（手机号绑定 / 换绑、解绑），走既有 `AdminActionEvent` 基类，审计监听（1.0.0）无需改动即兼容。
- **措辞中性化**：可信应用授权类型拒绝文案与内部 reader / 开放 API 路径注释去除具体凭证产品指名，改为按协作契约表述。

## 新增或扩展测试

- 本模块为纯契约层无行为逻辑；常量消费断言由 server-starter 1.3.0 的主体 ID 生成 / 回填、手机号挑战状态机与频控测试承载。

## 向后兼容性

- 纯增量发布（新增常量 / 枚举值 / 文案调整），无既有 API 删除或签名变更；文案变化（授权类型拒绝提示）不影响 API 契约，1.1.3 消费方不受影响。

## 升级指南

- 直接升级坐标即可；与 `simple-iam-server-starter:1.3.0` 同批部署时按版本映射表对齐。
