# 登录认证与会话

IAM Server 认证域：本地账号登录（渐进验证码、失败锁定）、外部身份源登录（LDAP / OIDC）与身份归一、会话生命周期、登出与吊销。模块总览与端点索引见根 [README](../../README.md)，配置参考见 [配置与多实例部署](配置与多实例部署.md)。

## 浏览器登录（本地账号 + 渐进验证码 + 失败锁定）

```mermaid
sequenceDiagram
    autonumber
    participant B as 浏览器(Vue)
    participant F as SecurityFilterChain
    participant C as IamAuthRestController
    participant CAP as CaptchaVerificationSupport
    participant P as 验证码适配器(SPI)
    participant A as AuthenticationService
    participant POL as LoginFailurePolicySupport
    participant S as SessionService

    B->>B: GET /iam/web/auth/csrf 取 CSRF token
    B->>C: POST /iam/web/auth/login {provider?, username, password, captchaId?, captchaAnswer?}
    F->>F: CSRF 校验
    C->>CAP: enforce（登录前置人机判定）
    alt captcha.enabled=false 或 未装配 CaptchaProvider
        CAP-->>C: 放行（组件缺失降级，warn 日志）
    else Redis 失败计数(与登录计数同维度) ≥ captcha.threshold(默认2)
        alt 缺 captchaId/captchaAnswer
            CAP-->>B: 401 CAPTCHA_REQUIRED + captchaRequired=true
        else 验证码校验失败
            CAP-->>B: 401 CAPTCHA_INVALID + captchaRequired=true
        end
    else 计数未达阈值
        CAP-->>C: 放行
    end
    C->>A: authenticate(username, password)
    A->>A: findByUsername
    alt 用户不存在
        A->>POL: recordLocalFailureForUnknownUsername（爆破不存在用户名同样计数，渐进触发验证码）
        A-->>B: 401 BAD_CREDENTIALS
    else 外部身份源账号（无本地密码）
        A->>POL: 失败计数（禁止走本地密码登录）
        A-->>B: 401 BAD_CREDENTIALS
    else 本地账号 → assertLocalLoginAllowed（禁用 / DB 锁定期直接拒绝，不比对密码）
        A->>A: PasswordEncoder.matches
        alt 密码错误
            A->>POL: 失败计数 +1
            alt 达 max-attempts(默认5)
                POL->>POL: 写 locked_until = now + lock-minutes(默认15min)<br/>发 ACCOUNT_LOCKED 审计
            end
            A-->>B: 401（登录失败）
        else 密码正确
            A->>POL: recordLocalSuccess（清计数 / 清锁 / 记 lastLoginAt）
            A-->>C: 用户实体
            C->>S: establishSession
            Note over S: revokeActiveByServletSessionId 踢同会话旧登录<br/>→ setMaxInactiveInterval(expires-in)<br/>→ 写 SPRING_SECURITY_CONTEXT<br/>→ createBoundSession
            C->>C: 发 LOGIN_SUCCEEDED 审计（带 ip / ua）
            C-->>B: 200 用户信息（Set-Cookie JSESSIONID）
        end
    end
```

要点：

- 验证码先于凭据校验：验证码失败不消耗密码失败次数，也不泄露"密码是否正确"；失败计数在 Redis、与登录失败策略同维度
- 未知用户名的爆破同样计数渐进触发验证码（防用户名枚举）
- 锁定状态存数据库 `locked_until`，跨实例生效；锁定期内不比对密码（防暴力破解窗口）；管理员可 `PUT /iam/admin/users/{userId}/unlock` 手动解锁（清 `locked_until` 与失败计数，发 `UNLOCKED` 审计），不等 15 分钟自动过期
- 登录成功会先撤销同一 Servlet 会话上的旧登录（切换账号不留旧身份）
- 登录成功 / 失败均发认证族审计事件（带来源 ip 与 User-Agent）

## 自助修改密码与首登强制改密

登录响应携带 `mustChangePassword`：管理员建号（`createUser`）与重置密码（`resetPassword`）置 `iam_user.must_change_password=1`——管理员发出的都是临时密码；自助改密成功清零。

```mermaid
sequenceDiagram
    autonumber
    participant B as 浏览器(Vue)
    participant F as IamMustChangePasswordFilter
    participant C as IamAuthRestController
    participant U as UserService
    participant SS as SessionService
    participant O as OAuth2 授权行 + refresh 族

    Note over B: 首登（或被重置后）：login 响应 mustChangePassword=true<br/>前端跳改密页
    B->>F: 任一 Web / 管理端点请求
    alt 标记未清 且 路径不在白名单
        F-->>B: 403 {code=AUTH_009}（改密 / 登出 / csrf / me 等白名单放行）
    end
    B->>C: PUT /iam/web/auth/password {oldPassword, newPassword}
    C->>U: changePassword(userId, old, new, currentSessionId)
    U->>U: assertAccountUsable + 外部身份源拒绝（AUTH_010）
    U->>U: 旧密码校验（错则 recordLocalFailure，与登录同锁定策略）
    U->>U: 策略校验（AUTH_011）→ encode 落库 → 标记置 0 → 清失败计数
    U->>SS: revokeAllByUserIdExcept(当前会话)——踢其他终端
    U->>O: 旧密码签发的授权行 + refresh 族全失效
    U-->>U: 发 PASSWORD_CHANGED 审计
    C-->>B: 204（当前会话保留）
```

要点：

- 错旧密码计入凭据失败计数：改密端点与登录共用锁定策略，爆破旧密码同样触发账号锁定；改密成功顺带清失败计数与锁定（`locked_until` 置空）
- 踢其他终端保留当前会话：改密完成后当前浏览器不掉线，其余终端（含旧 refresh token）全部失效
- 标记同步走 principal 热刷新机制：`IamSessionValidationFilter` 每请求从用户实体对齐 `mustChangePassword`，改密成功后拦截立即解除，无需重登
- 拦截范围两条链（Web `/iam/web/**` 与管理 `/iam/admin/**`）；`password.must-change-enforcement` 仅测试场景可关，生产关闭等于放弃首登强制改密防线
- 外部身份源（LDAP / OIDC）用户改密与被重置均拒绝（AUTH_010）：其密码由外部系统管理，若允许重置会置须改密标记而改密又被拒，形成永久锁死

## 外部身份登录——LDAP 凭证型

LDAP 模式下用户在本服务登录页输入域账号密码，密码由上游 LDAP 验证（bind），账号按首次见到时归一。

```mermaid
sequenceDiagram
    autonumber
    participant B as 浏览器(Vue)
    participant C as IamAuthRestController
    participant E as ExternalLoginService
    participant A as LDAP 适配器(SPI)
    participant L as LDAP 服务
    participant N as 外部身份归一
    participant S as SessionService

    B->>C: POST /iam/web/auth/login {provider:"ldap-password", username, password}
    C->>E: credentialLogin(provider, username, password)
    E->>A: authenticate(username, password)
    A->>L: manager DN 搜索用户条目
    L-->>A: 用户条目(DN + 属性)
    A->>L: 以用户 DN + 密码 bind
    alt bind 失败
        L-->>A: 拒绝
        A-->>E: 认证失败（按 provider+username 维度计数锁定）
        E-->>B: 401
    else bind 成功
        A-->>E: ExternalIdentity(externalId=配置属性或DN, username/displayName/email)
        E->>N: 归一(identitySource, externalId, profile)
        N-->>E: 本地用户（见"外部身份归一"）
        E-->>C: 本地用户
        C->>S: establishSession
        C-->>B: 200 用户信息
    end
```

login 端点对凭证型外部登录的错误分流（controller 内 `@ExceptionHandler`）：上游不可用 503（`EXTERNAL_PROVIDER_UNAVAILABLE`）、登录方式不存在 404、其余业务错误 401。

## 外部身份登录——OIDC 跳转型

```mermaid
sequenceDiagram
    autonumber
    participant B as 浏览器(Vue)
    participant C as IamAuthRestController
    participant SES as HttpSession(spring-session)
    participant A as OIDC 适配器(SPI)
    participant IdP as 上游 IdP

    B->>C: GET /iam/web/auth/authorize/oidc?redirect=/app
    C->>C: providerRegistry 取 provider / safeRedirectTarget 校验（仅站内路径）
    C->>SES: 存 state（防重放）与登录完成后的回跳目标
    C-->>B: 200 {authorizeUrl}（前端跳转上游，非 302）
    B->>IdP: 跳转 authorizeUrl（带 state / scopes）
    B->>IdP: 用户在上游完成登录
    IdP-->>B: 302 /iam/web/auth/callback/oidc?code&state
    B->>C: GET /iam/web/auth/callback/oidc?code&state
    C->>SES: consumeState（state 一次性消费，会话属性级绑定）
    alt state 无效/过期/已用
        C-->>B: 302 /login?error=login-failed
    end
    C->>A: completeBrowserLogin(code)
    A->>IdP: token-uri 换 token + jwk-set-uri 验签 ID token（iss 校验）
    A-->>C: ExternalIdentity(externalId=sub)
    C->>C: 归一 + establishSession
    C-->>B: 302 登录完成目标（authorize 暂存的 redirect，缺省门户首页）
```

要点：

- `state` 为 UUID、存 HttpSession 属性（spring-session 下多实例互认），回调时一次性消费——防 CSRF / 跨站授权码注入
- 回调失败 302 回登录页并附 `error` 查询参数；错误码默认透传前端引导，仅账号锁定（`ACCOUNT_LOCKED`）降级为 `login-failed`——锁定事实不向未认证方泄露，防回调爆破探测；发起时登录方式不存在返回 404
- 跳转型失败按 `provider` 维度计数（上游故障不锁单个用户）

## 外部身份归一（三步判定）

```mermaid
flowchart TD
    A[外部身份认证成功] --> B{已绑定该<br/>identitySource + externalId ?}
    B -- 是 --> C[直接复用本地账号]
    B -- 否 --> D{存在同名本地账号?}
    D -- 是 --> E[拒绝：绝不自动并号<br/>防接管，提示管理员预绑定]
    D -- 否 --> F{provisioning-mode ?}
    F -- jit --> G[自动创建本地账号<br/>密码哈希=随机UUID（本地不可登录）]
    F -- pre-bound-only --> H[拒绝：仅预绑定身份可登录]
    C --> I[establishSession 建会话]
    G --> I
```

同名拦截是安全底线：外部身份源对"谁能叫这个用户名"的判定与本地体系不一致，自动并号等于把账号控制权交给上游。

## 会话生命周期

```mermaid
sequenceDiagram
    autonumber
    participant B as 浏览器
    participant F as 会话过滤器
    participant SS as SessionService
    participant DB as iam_session(MySQL)
    participant R as Redis(spring-session)

    Note over B,R: 建立：登录 establishSession
    SS->>DB: createBoundSession（issuedAt, expiresAt=now+expires-in）
    SS->>R: 写 spring-session（JSESSIONID）
    loop 每个携带会话的请求
        B->>F: 请求(JSESSIONID)
        F->>R: 恢复 Servlet 会话
        F->>SS: 校验 + touchIfNeeded
        SS->>SS: 双时钟判定 expiresAt=min(now+expires-in, issuedAt+absolute-expires-in)
        alt 会话已过期 / 已吊销
            F-->>B: 401
        else 活跃 且 距上次续期 > renew-threshold
            SS->>DB: 定向 UPDATE 续期（status=1 守卫；节流窗内零写）
        end
        F-->>B: 正常响应
    end
    Note over B,R: 判死：空闲超 expires-in，或绝对时长到 absolute-expires-in（强制重认证）
```

要点：

- 双时钟：无论怎么活跃，`absolute-expires-in`（默认 10 小时）到点必须重新认证；滑动续期只前移 `expires_at`，不改 `issued_at`
- 续期节流：节流窗（默认 300s）内的活跃请求不落库，空闲用户零写
- 多实例互认：会话状态在 MySQL + Redis，任何实例都能校验与续期，无需粘性路由

## 登出与联动吊销（单端）

```mermaid
sequenceDiagram
    autonumber
    participant B as 浏览器
    participant C as IamAuthRestController
    participant SS as SessionService
    participant DB as iam_session
    participant R as Redis
    participant O as oauth2_authorization
    participant SSE as MessageSseService

    B->>C: POST /iam/web/auth/logout
    C->>SS: revokeSession(当前会话, cause=LOGOUT)
    SS->>DB: 置 status=INACTIVE + revokedAt
    SS->>R: 删 spring-session 键
    SS->>O: revokeByServletSessionIdHash（删除该会话签发的全部 OAuth2 授权行）
    SS->>SSE: 广播 EVICT_HASH（按 Servlet 会话哈希跨实例精确断流该端 SSE 连接）
    SS-->>SS: 发会话族 REVOKED 审计（cause 区分登出 / 重登踢旧）
    C-->>B: 200（cookie 失效）
```

登出不只是删 Servlet 会话：该会话签发过的所有 token（授权行）一并物理删除，资源端后续验证全部失败。

## 用户级全端吊销

禁用用户、删除用户、管理员重置密码时触发 `revokeAllByUserId`：

```mermaid
flowchart LR
    A[管理员操作<br/>禁用/删除/重置密码] --> B[revokeAllByUserId]
    B --> C[删 Redis spring-session<br/>该用户全部会话]
    B --> D[删除该用户全部 oauth2_authorization 行]
    B --> H[吊销该用户全部 refresh token 族]
    B --> E[批量置 iam_session status=INACTIVE]
    B --> F[SSE 广播 EVICT<br/>该用户所有连接断流]
    B --> G[发布审计事件]
```
