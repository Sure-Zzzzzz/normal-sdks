# 1.1.2

## 发布信息

- 类型：Bugfix
- 基线版本：1.1.1

## 变更

- IAM 返回 401 时清理当前 Profile 的 Token 缓存。
- 缓存清理会删除本实例 L1 和分布式 L2，并通过 SmartCache 失效通知同步其他实例。
- 清理后自动重放同一业务请求一次；重放仍 401 时还原 IAM 原始 401 响应。

## 兼容性

- 重放上限固定为一次，不会形成 401 循环。
- 非 401 触发的 RetryableException 继续立即上抛，本版本不新增网络重试语义。
- default Profile 也会执行同样的 401 清理和一次重放。
- 契约方法、配置键和认证头写入语义不变。
