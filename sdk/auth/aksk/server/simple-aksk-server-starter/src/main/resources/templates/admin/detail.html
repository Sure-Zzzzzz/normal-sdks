编辑 OAuth2 Scope
多个 Scope 用逗号分隔
⚠️ 检测到回车换行，请使用逗号分隔
Scope 格式说明：
OAuth2 Scope 仅表示令牌请求范围，不是 API permission 或 DATA grant。应用授权请使用 Client 详情中的“管理应用授权”入口单独配置。
注意：修改后，新签发 Token 使用新的 Scope；已签发 Token 不会被 Scope 修改自动撤销。
撤销所有Token
⚠️ 确定要撤销此Client下所有活跃Token吗？

此操作不可恢复，该Client需要重新换取Token才能继续使用。

已过期和已撤销的Token不会被处理。
