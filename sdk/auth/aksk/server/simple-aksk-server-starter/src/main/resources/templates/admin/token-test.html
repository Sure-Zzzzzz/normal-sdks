使用说明

        

        

            
1. 获取AKSK

            
在AKSK管理页面创建平台级或用户级 AKSK；Client Secret 仅在创建或重置成功时显示一次。


            
2. 换取Token

            
使用 Client ID 和 Client Secret 通过 OAuth2 Client Credentials Grant 换取 Access Token。


            
3. 验证和撤销

            
本页可对本次换取的 Token 执行 API 调用、带认证 Introspect、匿名 Introspect 对比和撤销；结果只展示状态和有效性摘要。


            
4. Token管理

            
可在Token管理页面查看、搜索、删除 Token。
