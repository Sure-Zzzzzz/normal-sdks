# 2.0.0（2026-10-30）

## 类型

Feature / 契约升级

## 依赖

- 无运行时依赖；保持纯 Java 8+ 客户端契约层。
- 与 `smart-license-core:2.0.0` 的协议 2 业务语义对齐由传输实现负责，本模块不引入 Core、Spring、HTTP 或认证依赖。

## 变更

- 固化 `LicenseServerClient` 的在线判定、候选授权发现、额度操作和信任资料同步契约。
- 增加完整请求值对象与严格响应校验，保留历史便捷入口并对缺少必要上下文的调用明确拒绝。
- 明确人员、服务和部署三种绑定形态，以及分页、围栏、幂等、吊销资料和最近有效快照语义。
- 明确聚散边界：本模块只提供契约；远端聚形态由独立传输 starter 装配，散形态由调用方自备实现。

## 兼容性

- Java 8+。
- 2.0.0 为协议 2 客户端契约版本；传输 starter 必须使用相同的 `simple-license-client-core:2.0.0`。
- 未改变旧接口签名；不完整的历史便捷入口仍保留，但会在发起远端请求前抛出异常。

## 验证

- `:sdk:license:client:simple-license-client-core:cleanTest` 全量通过。
- 独立 Maven 消费仅解析正式坐标，不依赖仓内源码组合。
